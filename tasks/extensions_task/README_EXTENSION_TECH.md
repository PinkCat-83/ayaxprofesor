## 1. Architecture

Single-page application. No build step, no external dependencies. Audio is generated via the Web Audio API (no audio files).

**Key constraint:** The task uses `fetch` to load `data.json`, so it must be served over HTTP — it does not work when opened directly from the filesystem.

---

## 2. Data Format (`json/data.json`)

```json
{
  "levels": {
    "1": {
      "PDF": "Documento que se lee bien en cualquier dispositivo"
    }
  },
  "links": {
    "PDF": "https://es.wikipedia.org/wiki/PDF"
  },
  "config": {
    "1": { "pairs": 5, "lives": 3, "minNew": 5 }
  }
}
```

| Key | Description |
|---|---|
| `levels` | Extensions grouped by level with their description. Level keys are strings (`"1"`, `"2"`, …). |
| `links` | Wikipedia URL per extension. Used in the Library view. |
| `config` | Pairs, lives and minimum new extensions per level. Must have an entry for every level in `levels`. |

Adding a new level requires entries in all three objects.

## 3. Arrow System

Arrows are drawn on a `<canvas>` element overlaid on the game area. Coordinates are calculated from the bounding boxes of the extension and description boxes at draw time.

| State | Color | Thickness |
|---|---|---|
| Dragging / returning | Semi-transparent black | 4 px |
| Correct (permanent) | Green `#4CAF50` | 4 px |
| Wrong (fades out) | Red `rgba(255,80,80,…)` | 4 px |

> Any CSS change that affects the size or position of the game area (padding, margin, flex layout) will shift arrow coordinates. Always verify arrow alignment after layout changes.

---

## 4. Sound System

All sounds are generated by the **Web Audio API** — no external audio files. Can be toggled on/off at any time with the 🔊 button.

| Event | Sound |
|---|---|
| Click | Short high-pitched tone |
| Correct | Ascending glissando |
| Wrong | Brief low tone |

---

## 5. Main Menu Layout

Two zones:

- **Title** — centered at the top, full width.
- **Body** — row with the mascot on the left and the difficulty selector + Library button on the right.

On returning to the menu (from game or Library), the page auto-scrolls to the top to avoid visual displacement.
